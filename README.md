# Kooly — школьный помощник (интерфейс на эстонском)

**Открыть:** https://ivanpostolenko3-ai.github.io/kooly/ (на iPhone: Safari → «Поделиться» → «На экран „Домой“»)

Веб-приложение (PWA) для iPhone и любого браузера: без App Store и подписки.
Все данные хранятся только на устройстве (localStorage).

## Вкладки

- **Praegu** — какой идёт урок и таймер до конца, на перемене — до следующего урока; кабинет; что взять на следующий урок.
- **Homme** — уроки следующего учебного дня и **готовый список для ранца**, собранный автоматически из расписания
  и базы вещей (сгруппирован: «Iga päev», затем по предметам). Остаётся только ставить галочки; есть «Märgi kõik pakituks».
  Вечером (время настраивается) приходит уведомление «Aeg ranits pakkida 🎒», клик открывает этот список.
- **Ülesanded** — задачи текстом или голосом (эстонский: «mata lk 42 reedeks», «homme füüsika kontrolltöö»)
  и **домашка из Stuudium**.
- **Edenemine** — успеваемость из Stuudium: общий средний (в % и ≈ по 5-балльной шкале), изменение за 2 недели,
  лучший предмет и предмет «под вниманием», карточки предметов с мини-графиком, распределение оценок,
  пройденные курсы по выбору; экран предмета — график всех оценок, описание, комментарий учителя, тема урока.
  Обновляется вместе с домашкой. «AR» (arvestatud) в средний не входит.
- **Asjad** — база вещей: что брать каждый день (пенал, сменная обувь…) и что — для каждого предмета.
  Вещи выбираются из готового списка галочками; учебник/тетрадь/рабочая тетрадь — свои для каждого предмета.
  Можно добавить свою вещь.
- **Tunniplaan** — импорт из EduPage, уроки, звонки, предметы, тема (светлая/тёмная/авто), уведомления, копия данных.

## Запуск

- **Включить:** двойной клик по `start.command` — откроется браузер (`http://localhost:8000`).
- **Выключить:** двойной клик по `stop.command`.

Сервер (`server.py`) работает в фоне: отдаёт приложение, пересылает запросы к EduPage и забирает домашку из Stuudium.

## Stuudium

1. Ülesanded → «Ava Stuudium»: откроется отдельное окно Chrome со страницей входа.
2. Войди как обычно (пароль, Smart-ID или ID-карта) и отметь «Jäta mind meelde».
3. Закрой это окно Chrome и нажми «Too kodutööd».

Дальше «Uuenda» (и автоматически раз в час при открытии Kooly) забирает домашку через сохранённую сессию.
Пароль Kooly не видит и не хранит. Сессия лежит в папке `.stuudium-profile` (только на этом Mac);
«Katkesta ühendus» её удаляет. У Stuudium защита от ботов на странице входа — поэтому вход всегда делаешь ты сам.

Если Stuudium открылся, но домашка не нашлась, страница сохраняется в `.stuudium-debug.html` —
по ней можно поправить разбор (файл содержит личные данные, никуда его не публикуй).

## Телефон без Mac

Kooly на телефоне работает сам, без компьютера:

| Что | Как обновляется на телефоне |
|---|---|
| Расписание EduPage | само, раз в сутки — через облачный посредник |
| Меню столовой | само, раз в 3 часа — через облачный посредник |
| Домашка и оценки Stuudium | ярлык iOS «Kooly» на странице Stuudium в Safari → «Kleebi Stuudiumist» |
| Таймер, ранец, задачи, уведомления | всё прямо в приложении |

**Облачный посредник** — бесплатный Cloudflare Worker (папка `worker/`). Браузер не может сам читать
EduPage и сайт школы (они не разрешают CORS), посредник пересылает только эти запросы:
EduPage-расписание и страницы сайтов из `ALLOWED_SITES` (по умолчанию `nerg.ee`). Личных данных через него не идёт.

Развернуть (один раз):

```bash
cd worker
npx wrangler login     # вход в бесплатный аккаунт Cloudflare
npx wrangler deploy    # выдаст адрес вида https://kooly-proxy.<имя>.workers.dev
```

Адрес развёрнутого посредника уже прописан в приложении по умолчанию (`DEFAULT_PROXY_URL` в `connect.js`).
Другой адрес можно указать на телефоне: **Seaded → Ühendus**.

**Stuudium на телефоне** — в Kooly: Seaded → Stuudium → «Otsetee seadistamine» (2 минуты, один раз).
Ярлык читает только открытую страницу Stuudium и копирует домашку и оценки в буфер обмена; пароль никуда не уходит.

**Установка:** сайт на GitHub Pages → открыть в Safari → «Поделиться» → «На экран „Домой“».

## Ограничения (пока)

- iOS не даёт веб-приложениям присылать уведомления по расписанию без сервера: они приходят,
  пока Kooly открыт или недавно свёрнут.
- Голосовой ввод на эстонском зависит от браузера (в Chrome работает; в Safari — если поддерживается системой).
- Меню столовой с nerg.ee — в планах.

## Файлы

- `index.html` — каркас и нижние вкладки
- `styles.css` — оформление (две темы, шрифт Mulish из `fonts/`)
- `app.js` — расписание, таймер, ранец и база вещей, задачи, голос, уведомления, темы
- `edupage.js` — импорт расписания из EduPage
- `stuudium.js` — домашка из Stuudium (клиентская часть)
- `progress.js` — вкладка «Edenemine» (аналитика оценок)
- `connect.js` — откуда брать данные (сервер на Mac или облачный посредник), разбор меню и страниц Stuudium
- `worker/` — облачный посредник (Cloudflare Worker) для телефона
- `server.py` — локальный сервер на Mac: EduPage, страницы сайта школы, Stuudium через Chrome
- `start.command` / `stop.command` — включить / выключить сервер
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн и установка на экран «Домой»
